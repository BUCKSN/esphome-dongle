# esphome-dongle

Неофициальная открытая прошивка на ESPHome для Wi-Fi донглов на ESP32-C3, которые ставятся в кондиционеры и другие
приборы. Локальное управление через Home Assistant, без облака. Проект не связан с производителями приборов и донглов
и не является официальным проектом ESPHome.

**Состояние:** реализован протокол AUX, остальные появляются по отчётам. См. [устройства](docs/supported-devices.md) и
[донглы](docs/dongles.md).

## Возможности

- Управление режимами, вентилятором, жалюзи и датчиками прибора из Home Assistant.
- Страница донгла, открывается кнопкой или из Home Assistant, закрывается сама: состояние, обновление, ключ, RU/EN.
- Обновление с проверкой совместимости файла.
- Ключ шифрования создаётся на самом донгле.
- «Добавить своё устройство в прошивку»: записывает, что меняет каждая кнопка, и собирает отчёт. Команд устройству не отправляет.

## С чего начать

1. [Первичная прошивка](docs/first-flash.md): снимает копию заводской прошивки и записывает эту.
2. Нет вашей модели? Пройдите «Добавить своё устройство в прошивку» и отправьте отчёт через форму Issue.

## Сборка из исходников

    pip install esphome==2026.10.1
    git clone -b extra-bits https://github.com/BUCKSN/esphome_aux_ac_component vendor/esphome_aux_ac_component
    python tools/build.py

Готовые файлы появятся в `firmware/`: `.ota.bin` для страницы донгла, `.factory.bin` для первичной прошивки.

Файлы: `components/` компоненты, `profiles/` шаги и расшифровка, `devices/` конфигурации, `tools/flash.py` прошивка,
`docs/` документация, `docs/notes.md` заметки о протоколе.
