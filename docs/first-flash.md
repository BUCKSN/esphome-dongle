# Первичная прошивка

English: [first-flash.en.md](first-flash.en.md). Windows и macOS пока не проверены, на Linux проверяется автором.

Прошивка один раз идёт через провода, дальше обновления ставятся со страницы донгла. Заводская прошивка сохраняется
и её можно вернуть. Ответственность за прибор и гарантию лежит на вас.

## Что понадобится

- Донгл, **снятый с прибора**.
- Адаптер USB-UART 3,3 В с выводом 5 В, например CP2102, CH340 или PL2303.
- Планка USB от старого ПК: гнездо USB-A и кабель на материнскую плату с отдельными контактами. С ней не нужно паять.
- Мультиметр для проверки контактов и провода «мама-мама».

**Не вставляйте донгл в USB компьютера.** Разъём USB-A здесь только форма: внутри UART, а не USB. Не вставляйте в порт
прибора обычные USB-устройства: в порту кондиционера другое напряжение.

## Подключение

Цвета в кабелях планки бывают разными. Определите контакты мультиметром в режиме прозвонки: контакт 1 гнезда USB-A
находится с краю, рядом с ним контакт 2.

| Адаптер | Контакт USB-A | Обычный цвет провода |
|---|---|---|
| 5V | 1 | Красный |
| TX | 2 (рядом с питанием) | Белый |
| RX | 3 | Зелёный |
| GND | 4 | Чёрный |

Контакты RX и TX проверены не на всех платах. Если донгл не отвечает, поменяйте TX и RX местами, это безопасно.
Питание подайте **после** шага с кнопкой, поэтому провод 5V удобно подключать последним.

## Прошивка

1. Скачайте из раздела Releases программу для своей системы: `esphome-dongle-flash-windows`, `-macos` или `-linux`.
   В Linux сделайте файл исполняемым: `chmod +x esphome-dongle-flash-linux`. Запускайте из своей папки: копия сохранится рядом.
2. Windows и macOS предупредят о неподписанной программе. Это ожидаемо: проверьте контрольную сумму по `SHA256SUMS.txt`
   и разрешите запуск вручную. Адаптеру может понадобиться драйвер производителя.
3. Подключите адаптер к компьютеру без провода 5V, затем запустите программу и следуйте вопросам.
4. Когда программа попросит: зажмите кнопку на торце донгла, подключите 5V, отпустите кнопку, нажмите Enter.
5. Программа дважды снимет полную копию памяти, это около 12 минут. Прервите её, если копии не совпали.
6. **Сохраните папку `esphome-dongle-backup-...`.** В ней ваш личный токен: не публикуйте её. Только она вернёт заводскую прошивку.
7. Подтвердите запись, дождитесь сообщения «Готово».

Вернуть заводскую прошивку: запустите программу с параметром `--restore папка/dump-1.bin`.

## Настройка

1. Отключите питание, снимите провода и вставьте донгл в выключенный прибор, затем включите прибор.
2. Подключитесь к сети `esphome-dongle-XXXXXX` без пароля. Откроется страница донгла: выберите свой Wi-Fi и введите пароль.
3. При первом запуске страница остаётся открытой час после подключения. Откройте `http://esphome-dongle-XXXXXX.local/` или IP-адрес из роутера. Позже страницу открывает короткое нажатие кнопки.
4. Добавьте устройство в Home Assistant, интеграция ESPHome. Настройте в доверенной сети: ключ для шифрования показан на
   странице донгла в разделе «Ключ Home Assistant».

Сменить Wi-Fi можно на странице донгла: при неудаче он через минуту вернётся на прежнюю сеть.

Сброс настроек: удерживать кнопку. Через 2 с загорится красный (если светодиоды включены), через 10 с он замигает, кнопку можно отпустить. Стираются Wi-Fi и ключ. Новый ключ создаётся при следующем запуске.
