# Поддерживаемые устройства

Цель проекта: все устройства, которые поддерживает донгл производителя. **Сейчас реализован только протокол AUX.**
Остальные протоколы появляются по отчётам раздела «Добавить своё устройство в прошивку». Строка добавляется только с ссылкой на отчёт или
проверку. Названия моделей приведены для описания совместимости, проект не связан с их производителями.

| Статус | Значение |
|---|---|
| Проверено | Диагностика пройдена, управление работает на реальном устройстве |
| Только чтение | Состояние читается, команды не подтверждены |
| Нужен отчёт | О модели спрашивали, данных нет |
| Не работает | Проверено, совместимости нет |

| Устройство | Пульт | Протокол | Статус | Тестировалось с донглом | Подробности |
|---|---|---|---|---|---|
| Ballu BSW/in-09HN1_24Y | YKR-L/201E | AUX | Проверено | HOMMYN HDN/WFN-02-01 | [карточка](devices/ballu-bsw-09hn1.md) |

Подсказка: если модели нет здесь, посмотрите
[список aux_ac](https://github.com/GrKoR/esphome_aux_ac_component/blob/master/docs/AC_TESTED.md). Там модели проверены с
компонентом `aux_ac`, а не с этой прошивкой.
